# Умники — прокачка мышления для детей

Игровое веб-приложение (PWA): числа, логика, пространство, **внимание, память и шахматы**. Без рекламы и трекеров, работает офлайн,
на четырёх языках (русский, белорусский, чешский, английский). Прогресс хранится на устройстве; по желанию — вход через Google и облако.

## Профили детей (F2, F3)

До 3 детей в одной семье: имя или псевдоним, возраст 5–10, картинка-аватар (питомец). Общие для семьи PIN и лимит времени, прогресс у каждого ребёнка свой. Если детей больше одного, при запуске показывается «Кто занимается?» — ребёнок заходит тапом по своей картинке. Добавлять, менять и удалять профили можно только в родительской зоне. Возраст задаёт стартовый уровень навыков (5–7 → 1, 8–9 → 2, 10 → 3) и для 5–7 лет оставляет задания почти без чтения. Хранение: `umniki.v2` (старое `umniki.v1` переносится само), в облаке — документ `users/{uid}` с полем `fam`; прежний формат с полем `s` читается как один ребёнок.

## Глоссарий, приватность, данные (F13, GDPR)

- **Словарик** (`glossary.js`, 129 терминов RU/BE/CS/EN): экран «Словарик» в профиле и родительской зоне с поиском на любом языке. В тексте задания слова из словаря подчёркнуты точками: тап показывает перевод, ничего не стоит и не считается ошибкой. Какие слова спрашивали, видно в отчёте родителя. Переводы мои, носителями не проверены.
- **Приватность и cookie:** при первом запуске — информационный баннер (рекламы и трекеров нет, используется только необходимая память браузера). SDK Google Firebase не загружается, пока родитель не согласится на облако при входе через Google; дата согласия хранится на устройстве.
- **Данные** (родительская зона → «Данные и приватность»): скачать всё в JSON (хэш PIN не выгружается), отозвать согласие (данные в облаке удаляются), удалить всё навсегда (устройство + облако + аккаунт Firebase). Если облако недоступно, ничего не удаляется «наполовину».
- Тексты политики — краткая справка, не юридический документ; оператору нужно добавить свои реквизиты и показать юристу.

## Как устроена игра
- **Дневной маршрут:** 4 мини-игры по разным навыкам (сначала те, что давно не тренировались), 10–15 минут, потом экран «На сегодня всё» без автопродолжения.
- **Карта навыков:** числа 🔢, логика 🧠, пространство 📐, внимание 👀, память 🧩, шахматы ♟️ — по 5 уровней.
- **Адаптивная сложность:** каждые 10 ответов с первой попытки уровень навыка оценивается: ≥ 80% верных — выше, < 40% — мягко ниже.
- **Без наказаний:** нет жизней, ошибка ничего не отнимает; пропущенный день ничего не сбрасывает (вместо «серии» — дни занятий за неделю).
- **Награды:** звёзды, XP и уровни, монеты, магазин друзей и шляпок, достижения.
- **Шахматы:** 9 уроков-обучалка (фигуры, взятие, шах, мат) и ~150 задач («мат в 1 ход», «возьми незащищённую фигуру», «защити фигуру»).
  Неверный ход можно повторить без штрафа.
- **Родительская зона** (профиль → «Родительская зона», PIN из 4 цифр): отчёт, язык, аккаунт, имя, сброс, смена PIN и **дневной лимит времени**
  (10–60 минут). Когда время выходит, занятие мягко завершается (решённое сохраняется), ребёнок видит экран отдыха; родитель может добавить время с PIN.
  Забыли PIN — сброс через вход Google. PIN хранится только в виде хэша; это защита «от ребёнка», а не от взломщика.
- **Двуязычный режим** (родительская зона → «Двуязычный режим»): второй язык из остальных трёх (например, чешский ↔ русский), режимы «микс» (доля 10/20/30/50/80%, по умолчанию 30%)
  и «погружение». Язык каждого задания выбирается целиком; кнопка 🌐 («не понял») показывает **то же задание** на другом языке без штрафа (задания воспроизводимы по «зерну»).
  Доля в среднем точная (дробный остаток переносится между занятиями), а при частых «не понял» раз в неделю автоматически снижается. В отчёте — блок про второй язык.
- **Отчёт для родителя** (родительская зона → «Отчёт для родителя»): время и дни за неделю, точность с динамикой, паспорт навыков (радар), совет «чем помочь дома», печать.

## Файлы
| Файл | Назначение |
|---|---|
| `index.html`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icons/` | оболочка PWA и офлайн |
| `app.js` | интерфейс, игровой цикл, облако (Firebase) |
| `glossary.js` | глоссарий терминов и поиск слов в тексте задания |
| `skills.js` | навыки, адаптивность, маршрут дня, история занятий (чистая логика, тестируется в Node) |
| `gens.js`, `gens_ext.js`, `gens_more.js` | генераторы задач (числа, логика, пространство, внимание, память; в `gens_more.js` — поворот, симметрия, «где стоит», «без пары» и задания для 5–7 лет на картинках) на 4 языках |
| `chess_engine.js` | правила ходов, шах, мат (собственный компактный движок) |
| `chess.js`, `chess_data.js` | шахматные уроки, задания, доска; банк задач (создан `tools/gen_chess.js`) |
| `firestore.rules` | правила доступа к облаку: каждый видит только свой документ |

## Запуск на телефоне
Выложить папку на статический хостинг по https (например, GitHub Pages), открыть ссылку и «Добавить на главный экран».
Локально: `python3 -m http.server 8000` → `http://localhost:8000`.

## Тесты
```
npm test            # быстрые тесты без браузера: навыки и симуляции, движок (perft), банк шахматных задач, все генераторы на 4 языках
npm run test:e2e    # сквозной тест в браузере (нужен Playwright): все экраны на 4 языках, игровой цикл, облачное слияние, родительская зона
                    # (можно запускать частями: node tests/e2e.js lang | game | parent | bil; профили детей: node tests/profiles.js; согласие, экспорт, удаление, словарик: node tests/privacy.js)
npm run gen:chess   # пересоздать банк шахматных задач (детерминированно)
```

## Облако (по желанию)
Вход через Google сохраняет прогресс в Firestore (`users/{uid}`); на новом устройстве его можно вернуть кнопкой «У меня уже есть профиль».
Конфиг Firebase в `app.js` публичный; защита данных держится на правилах из `firestore.rules`. Вход работает только на разрешённых доменах
(Authentication → Settings → Authorized domains).
